# STM32F103C8T6-Microcontroller-PCB
A 2-layer microcontroller PCB designed around the STM32F103C8T6 ARM Cortex-M3 MCU. The board is powered using a regulated 3.3V supply derived from a 5V DC input and follows the STM32 reference manual and datasheet recommendations for power delivery, decoupling, reset circuitry, and programming interface implementation.
